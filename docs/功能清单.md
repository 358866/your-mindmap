# 功能清单

按"功能 → 在哪里用"整理，方便快速查找入口。

## 一、结构与布局

| 功能 | 入口 |
|------|------|
| 逻辑结构图（左/右） | 右侧「结构」面板 → 逻辑结构图 |
| 思维导图（左右分布） | 右侧「结构」面板 → 思维导图 |
| 组织结构图 | 右侧「结构」面板 → 组织结构图 |
| 目录组织图 | 右侧「结构」面板 → 目录组织图 |
| **时间轴**（横/纵/双向，共 5 种） | 右侧「结构」面板 → 时间轴 |
| **鱼骨图**（左/右，共 4 种） | 右侧「结构」面板 → 鱼骨图 |
| **表格** | 右侧「结构」面板 → 表格 |
| 单分支独立结构 | 选中节点 → 结构面板切换（只影响该分支） |
| **自由节点树切换结构** | 自由节点树根节点 → 右键 → 切换自由节点树结构 |

## 二、主题与外观

| 功能 | 入口 |
|------|------|
| 经典 / 深色 / 朴素主题 | 右侧「主题」面板对应页签 |
| **彩虹主题**（40+ 套） | 右侧「主题」面板 → 彩虹页签 |
| **手绘风格** | 设置 → 开启手绘风格 |
| **画布拖动动量** | 设置 → 开启拖动画布的动量效果 |
| **同级节点对齐** | 设置 → 开启同级节点对齐 |
| 水印 | 设置 → 水印（可仅导出时显示） |
| 背景图 | 节点样式 → 基础样式 → 内置背景图片 |
| **扩展字体** | 设置 → 字体管理，添加后在所有字体选择器中出现 |

## 三、节点内容与样式

| 功能 | 入口 |
|------|------|
| 富文本（粗体/斜体/下划线/颜色/字号/对齐） | 工具栏或节点样式面板 |
| 图片 | 工具栏图片按钮 / 粘贴图片 |
| 图标 | 工具栏图标按钮（分类图标库） |
| 标签 | 工具栏标签按钮 |
| 备注 | 工具栏备注按钮 |
| 超链接 | 工具栏链接按钮 |
| 附件 | 节点附件功能 |
| 数学公式 | 工具栏公式按钮（LaTeX） |
| 概要 | 工具栏概要按钮 / `Ctrl+G` |
| **外框（可不含子节点）** | 工具栏外框按钮；样式在 节点样式 → 外框样式 |
| 关联线（可加文字、**彩虹线条**） | 工具栏关联线按钮；样式在 基础样式 → 关联线样式 |
| **标注（可拖动对话框）** | 工具栏标注按钮；样式在 节点样式 → 标注样式 |
| **节点标记** | 工具栏插入标记 |
| **专属节点形状**（心形、五角星、三角、花朵、云朵、爆炸、水滴、火焰、标记等 13 种） | 节点样式面板 → 边框 → 形状 |
| 线型 / 线宽 / 箭头 | 节点样式面板 → 线条 |
| **连线虚线流动效果** | 节点样式 → 线条 → 开启流动效果（可设方向与周期） |

## 四、节点批量操作

| 功能 | 入口 |
|------|------|
| **逐行编号**（文本随修改自动更新） | 节点右键 → 编号节点文本（8 种样式） |
| **一键编号分支** | 节点右键 → 编号其子节点（首层/前两层/前三层/所有层） |
| **待办勾选** | 节点右键 → 添加待办 |
| **待办批量操作** | 节点右键 → 一键添加/完成/取消/删除子节点待办 |
| **隐藏节点文本** | 节点右键 → 隐藏文本 |
| 一键去除自定义样式 | 节点右键 → 一键去除自定义样式 |
| 多选统一改样式 | `Ctrl` 多选或框选 |
| 复制为纯文本 / Obsidian 内链 | 节点右键 → 复制为 |
| 导出单个节点为图片 | 节点右键 → 导出该节点为图片 |

## 五、导入

| 功能 | 入口 |
|------|------|
| 导入 `.smm` / `.json` | 右上角导入按钮 |
| 导入 Markdown / Txt | 导入按钮 / **粘贴 Markdown 或 Txt 内容导入** |
| 导入 **OPML** | 导入按钮 |
| 导入 **FreeMind（.mm）** | 导入按钮 |
| 导入 **Excel（.xlsx）** | 导入按钮（可选工作表） |
| 导入 XMind | 导入按钮 |
| **导入为当前激活节点的下级** | 导入对话框选项 |
| 解析多根内容为自由节点 | 导入对话框选项 |
| Markdown 转换数学公式 | 导入对话框选项 |

## 六、导出

| 功能 | 入口 |
|------|------|
| 思绪文件（.smm） | 导出对话框 |
| JSON | 导出对话框 |
| Markdown（可设标题层级与保留项） | 导出对话框 |
| Txt | 导出对话框 |
| **HTML**（单文件，内嵌 SVG） | 导出对话框 |
| **Excel（.xlsx）** | 导出对话框 |
| **FreeMind（.mm）** | 导出对话框 |
| **Mermaid（.mmd）** | 导出对话框 |
| **OPML** | 导出对话框 |
| PNG / JPG（可透明、可含背景） | 导出对话框 |
| SVG | 导出对话框 |
| **PDF（节点超链接可点击）** | 导出对话框 |

## 七、Obsidian 集成

| 功能 | 入口 |
|------|------|
| **smm 代码块嵌入编辑** | 在笔记里写 ```smm 代码块 |
| **新标签页预览为思维导图** | Markdown 文件右上角更多菜单（⋮） |
| 大纲模式双向编辑 | 右上角大纲图标 |
| 只读模式 | 底部工具栏 / 右上角 |
| 双向链接（linkdata） | 节点超链接指向其它笔记，自动记录反向链接 |
| 笔记内搜索节点 | 节点右键 → 在该节点下搜索 |
| 命令面板命令 | `Ctrl/Cmd + P` → 搜索 `smm` |

## 八、演示与专注

| 功能 | 入口 |
|------|------|
| **演示模式** | 底部工具栏播放图标 / 命令面板 |
| **填空模式** | 演示模式内 / 画布右键菜单；默认在 设置 → 演示配置 |
| **进入指定节点** | 节点右键 → 进入指定节点（顶部出现退出按钮） |
| 禅模式 | 设置或底部工具栏 |

## 九、文件与设置

| 功能 | 入口 |
|------|------|
| 文件名格式模板 | 设置 → 文件名格式 |
| 文件/图片/附件保存位置 | 设置 → 对应项 |
| 自动保存间隔 | 设置 → 自动保存时间 |
| 性能模式 | 设置 → 性能模式（大图建议开启） |
| 滚轮行为 | 设置 → 鼠标滚轮行为 |
| 新建节点行为 | 设置 → 创建新节点的行为 |
| 代码块初始高度 / 背景透明 | 设置 → 代码块相关项 |
| 语言 | 设置 → 语言（简中/繁中/EN/VI） |
| Markdown → 思维导图 | 命令面板或文件菜单 → 转换为思维导图文档 |
| 思维导图 → Markdown | 命令面板或文件菜单 → 转换为Markdown文档 |
| 切换 Markdown / 思维导图视图 | 命令面板 → 切换 Markdown / 思维导图视图 |
