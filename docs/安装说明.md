# 安装说明

## 前置条件

| 项目 | 要求 |
|------|------|
| Obsidian | 1.8.3 或更高版本（设置 → 关于 可查看） |
| 操作系统 | Windows / macOS / Linux / iOS / Android |
| 需要下载的文件 | `main.js`、`manifest.json`、`styles.css` |

> 自 Obsidian 1.4 起，未在社区插件市场发布的插件需要在设置中关闭"受限模式"
> （旧版本叫"安全模式"）才能启用。

---

## 一、手动安装（推荐）

### 第 1 步：找到仓库的插件目录

打开你的 Obsidian 仓库所在文件夹，进入 `.obsidian/plugins/`：

| 系统 | 示例路径 |
|------|----------|
| Windows | `D:\我的笔记\.obsidian\plugins\` |
| macOS | `~/Documents/我的笔记/.obsidian/plugins/` |
| Linux | `~/Documents/我的笔记/.obsidian/plugins/` |
| iOS / Android | 需通过文件管理 App 访问仓库文件夹，见下方"移动端安装" |

> `.obsidian` 是隐藏文件夹。
> - Windows：在资源管理器"查看"中勾选"隐藏的项目"
> - macOS：在 Finder 中按 `Cmd + Shift + .` 显示隐藏文件

### 第 2 步：创建插件文件夹

在 `plugins` 目录下新建文件夹，名称**必须**是：

```text
your-mindmap
```

最终结构应为：

```text
<你的仓库>/
└── .obsidian/
    └── plugins/
        └── your-mindmap/
            ├── main.js
            ├── manifest.json
            └── styles.css
```

### 第 3 步：放入三个文件

从本仓库下载（Code → Download ZIP，然后解压），把以下 **3 个文件**复制进
`your-mindmap` 文件夹：

- `main.js`
- `manifest.json`
- `styles.css`

也可以直接用 `git clone`：

```bash
cd "<你的仓库>/.obsidian/plugins"
git clone https://github.com/<你的用户名>/your-mindmap.git your-mindmap
```

> 用 `git clone` 时仓库根目录就是插件目录，三个文件正好在根目录，无需再复制。
> 更新时在该目录执行 `git pull` 即可。

### 第 4 步：启用插件

1. 打开 Obsidian
2. 进入 **设置 → 第三方插件**
3. 如果是第一次安装第三方插件：先点 **关闭受限模式**（Turn off restricted mode）
4. 点右侧的 **重新加载插件**（Reload plugins）按钮，或整个 Obsidian 按
   `Ctrl + R`（macOS 为 `Cmd + R`）重新加载
5. 在"已安装插件"列表中找到 **Your Mindmap**，打开右侧开关

启用后：

- 左侧功能区会出现思维导图图标
- 按 `Ctrl/Cmd + P` 打开命令面板，输入 `smm` 可以看到本插件注册的全部命令

### 第 5 步：验证

在任意文件夹空白处右键 → **新建思维导图**，或点击左侧功能区图标。
如果生成了一张名为 `MindMap 日期.md` 的卡片并自动打开导图编辑界面，
说明安装成功。

## 二、移动端安装

移动端无法直接访问 `.obsidian` 文件夹，需要借助文件管理工具：

**iOS**

1. 用"文件"App 或 [Working Copy] 找到仓库目录
2. 显示隐藏文件后进入 `.obsidian/plugins/`
3. 新建 `your-mindmap` 文件夹，把三个文件放进去
4. 回到 Obsidian 重新加载并启用

**Android**

1. 用"文件管理"或"Solid Explorer"等工具进入仓库目录
2. 打开"显示隐藏文件"后进入 `.obsidian/plugins/your-mindmap/`
3. 复制三个文件后重新加载 Obsidian

> 移动端建议在平板上使用；小屏手机编辑体验受限，可用"只读模式"浏览。

---

## 三、更新插件

**手动安装的用户**

1. 从本仓库重新下载最新的 `main.js`（通常只需替换这一个文件）
2. 覆盖 `your-mindmap` 文件夹中的同名文件
3. 在 Obsidian 中按 `Ctrl/Cmd + R` 重新加载

**用 git clone 的用户**

```bash
cd "<你的仓库>/.obsidian/plugins/your-mindmap"
git pull
```

然后重新加载 Obsidian。

> 你的插件设置保存在同目录的 `data.json` 中，更新时**不要删除**该文件。

---

## 四、卸载 / 回滚

**卸载**

1. Obsidian → 设置 → 第三方插件 → 关闭 **Your Mindmap** 开关
2. 删除 `.obsidian/plugins/your-mindmap/` 文件夹

> 卸载插件不会删除任何导图文件（`.md` 以及旧版 `.smm.md`）。它们仍然保存在你的仓库里，
> 以后重新安装插件即可继续打开。

**回滚到旧版本**

把旧版本的 `main.js` / `styles.css` / `manifest.json` 覆盖回插件目录，
然后重新加载 Obsidian 即可。升级前建议先备份整个 `your-mindmap` 文件夹。

## 五、常见安装问题

| 现象 | 原因与解决 |
|------|-----------|
| 插件列表里找不到 Your Mindmap | 文件夹名不是 `your-mindmap`；或三个文件不在文件夹根目录 |
| 开关是灰色的，点不动 | 受限模式（安全模式）没有关闭：设置 → 第三方插件 → 关闭受限模式 |
| 提示"Failed to load plugin" | `main.js` 下载不完整（被浏览器截断）。重新下载，注意文件大小应为数 MB |
| 更新后没有生效 | 只覆盖了文件但没有重载：按 `Ctrl/Cmd + R` 或在插件页点"重新加载插件" |
| 打开导图是空白 / 只显示根节点 | 画布视图未适配：点底部工具栏的"适应画布"图标，或按 `Ctrl/Cmd + R` 重载 |
| 移动端打开很卡 | 在 设置 → Your Mindmap → 性能模式 中开启性能模式 |
| 与其它导图插件冲突 | 若同时装有其它注册了 `smm` 代码块语言的插件，代码块嵌入会失效（详见使用说明"代码块嵌入"一节），停用其中一个即可 |
| 插件设置被重置 | 目录下的 `data.json` 被删除或损坏。恢复备份或重新配置 |

## 六、安装前检查清单

- [ ] Obsidian 版本 ≥ 1.8.3
- [ ] 插件文件夹名为 `your-mindmap`
- [ ] 文件夹内恰好有 `main.js`、`manifest.json`、`styles.css` 三个文件
- [ ] 已关闭受限模式
- [ ] 安装后已重新加载插件或整个 Obsidian
- [ ] 已备份原有的 `data.json`（升级场景）
