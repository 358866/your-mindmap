## 一、快速上手

**三步画出第一张导图：**

1. 点击左侧功能区的**思维导图图标**（或右键文件夹 → 新建思维导图）
2. 自动生成 `MindMap 2026-01-01 12.00.00.md` 并在新标签页打开编辑界面
3. 选中根节点 → 按 `Tab` 加下级节点、按 `Enter` 加同级节点 → 直接输入文字

编辑会自动保存（默认停止输入 5 秒后写入文件），左下角状态栏会显示保存状态。

## 二、文件格式：`.md` 笔记里存的是什么

导图就是一张**普通 Markdown 笔记（`.md`）**，所以能被 Obsidian 正常搜索、双链、同步，模板类插件也能识别它。旧版本创建的 `.smm.md` 文件继续兼容，无需转换。
文件内部结构如下：

````markdown
---
path: MindMap 2026-01-01 12.00.00.md
tags:
  - simplemindmap
---
> 请勿修改除YAML外的任何信息
# metadata
```metadata
（思维导图数据，压缩编码）
```

# svgdata
```svgData
（缩略图数据）
```

# linkdata
```linkData
（双向链接数据）
```
````

**注意事项**

- 顶部 YAML 区可以自由编辑（例如加自己的 `tags`、`aliases`）
- `# metadata` / `# svgdata` / `# linkdata` 三个代码块**不要手动修改**，否则导图数据会损坏
- 笔记的 frontmatter 里带有 `simplemindmap` 标签，插件凭这个标签把你的笔记识别为导图并自动切换到导图视图（**删掉标签它就变回普通笔记**）
- 更早版本创建的 `.smm` 文件（纯 JSON 数据）也可以直接打开、编辑，保存后会升级为新格式
- 想把导图还原为普通笔记：文件右上角 **更多菜单（⋮）→ 转换为 Markdown 文档**（移除导图数据、保留大纲结构，文件名不变）；想另存一份大纲则用 **导出 → Markdown**

## 四、创建导图的五种方式

1. **功能区图标**：点击左侧思维导图图标，在默认位置新建
2. **文件列表右键**：在文件夹上右键 → 新建思维导图（在该文件夹创建）
3. **命令面板**：`Ctrl/Cmd + P` → 输入 `smm` → 选择对应命令
   - `新建思维导图`：创建空白导图
   - `新建思维导图并插入 Markdown 大纲`：把当前笔记的标题结构转成导图
   - `把 Markdown 预览为思维导图（新标签页）`
   - `进入演示模式`
4. **Markdown 转导图**：文件右上角 **更多菜单（⋮）→ 转换为思维导图文档**，插件会把标题层级解析成节点。对话框里选"覆盖转换"= 当前笔记直接变成导图（文件名不变），选"新建转换"= 另存一份副本；也可以手动给笔记加上 `simplemindmap` 标签
5. **smm 代码块**：在普通笔记里写 ```smm 代码块（见[第 12 节](#十二smm-代码块嵌入)）

## 五、节点操作与快捷键

### 插入节点

| 操作 | 快捷键 |
|------|--------|
| 插入子节点（下级） | `Tab` |
| 插入同级节点（后面） | `Enter` |
| 插入同级节点（前面） | `Shift + Enter` |
| 插入父节点 | `Shift + Tab` |
| 插入概要 | `Ctrl + G` |

### 编辑与移动

| 操作 | 快捷键 |
|------|--------|
| 编辑节点文字 | 双击节点 / `F2` |
| 上移节点 | `Ctrl + ↑` |
| 下移节点 | `Ctrl + ↓` |
| 复制 / 剪切 / 粘贴节点 | `Ctrl + C` / `Ctrl + X` / `Ctrl + V` |
| 删除节点（保留子节点） | `Delete` |
| 删除节点及其子树 | `Shift + Backspace` |
| 撤销 / 重做 | `Ctrl + Z` / `Ctrl + Y` |
| 全选 | `Ctrl + A` |

### 右键菜单

在节点上右键可看到完整功能：

- **插入节点**：同级 / 上方同级 / 子节点 / 父节点 / 概要
- **上移 / 下移节点**
- **收起 / 展开所有下级节点**
- **选择**：同层级所有节点 / 自身及下级节点 / 子节点
- **编号节点文本**：`1, 2, 3`、`1., 2., 3.`、`(1), (2)`、`a. b. c.`、`A. B. C.`、
  `i. ii. iii.`、`I. II. III.`、`一、二、三` 等 8 种样式（可"无编号"取消）
- **编号其子节点**：对整个分支一键编号，支持"编号首层 / 前两层 / 前三层 / 所有层"
- **添加待办**：给节点加勾选框；子节点支持一键添加 / 完成 / 取消 / 删除待办
- **隐藏文本**：把节点文字藏起来（做填空、复习卡片时很有用）
- **进入指定节点**：以该节点为临时根节点专注编辑，顶部出现"退出"按钮
- 删除 / 复制 / 剪切 / 粘贴节点
- **复制为**：纯文本 / Obsidian 内链
- **一键去除自定义样式**
- **导出该节点为图片**：复制到剪贴板 / 下载到本地
- **在该节点下搜索**

### 节点内容

节点支持富文本（加粗、斜体、下划线、颜色、字号、对齐），还可以插入：

- **图片**：工具栏图片按钮，或直接粘贴图片
- **图标**：内置分类图标库
- **标签**：`#标签` 形式
- **备注**：悬浮显示的长文本
- **超链接**：外部链接或 Obsidian 内部链接
- **附件**：任意文件
- **数学公式**：LaTeX 语法（支持 MathML / KaTeX 渲染模式）
- **概要**：给一组节点加括号汇总
- **外框**：给一组节点加边框，可选"不包含子节点"
- **关联线**：节点之间连线，可加文字
- **标注**：对话框形式的注释，可拖动位置

## 八、主题与样式

### 主题

点击右侧**主题图标**（调色板），分为四个页签：

- **经典**：明亮通用配色
- **深色**：暗色系
- **朴素**：低饱和度

点击缩略图即时应用；主题只改变样式，不会改动内容。

### 节点样式

点击右侧**节点样式图标**（衣服），可分别设置：

| 分组 | 可调项 |
|------|--------|
| **文字** | 字体（宋体 / 微软雅黑 / 楷体 / 黑体 / 隶书 / Arial 等，含自定义字体）、字号、加粗、斜体、下划线、颜色、对齐 |
| **边框** | 颜色、线宽、圆角、**形状**（矩形、菱形、平行四边形、圆角矩形、八边形、内外三角矩形、椭圆、圆形，以及**心形、五角星、三角形、花朵、云朵×4、爆炸、水滴×2、火焰、标记** 等专属形状） |

### 基础样式（全局）

## 九、节点高级功能

### 逐行编号（编号节点文本）

右键节点 → **编号节点文本** → 选择样式。节点文字会按行自动编号；**修改文字后编号自动更新**。
再次选择"无编号"即可取消。

### 一键编号（编号其子节点）

右键节点 → **编号其子节点** → 选样式，再选择范围：

- 编号首层 / 编号前两层 / 编号前三层 / 编号所有层

适合给大纲式导图快速加序号。

### 待办

右键节点 → **添加待办**，节点前出现勾选框，点击即可切换完成状态。
子节点批量操作：一键添加 / 完成 / 取消 / 删除子节点待办。

### 标记

工具栏 → **插入标记**，可以给节点加图示标记（优先级、进度、表情、符号等）。
在节点样式面板可调整标记位置。

### 标注

节点上的"标注"是对话框形式的浮动注释：

- 工具栏 → **标注**，在节点旁生成一个可拖动的注释框
- 可输入任意文字、拖动调整位置
- 外观在 节点样式 → **标注样式** 中调整

### 隐藏节点文本

右键 → **隐藏文本**。文字被隐藏但仍参与搜索与导出，适合做记忆卡片、
或演示时先隐藏再逐条展开。

### 进入指定节点

右键节点 → **进入指定节点**：以该节点为临时根节点专注编辑/演示，
顶部工具栏出现"退出"按钮返回完整导图。

### 手绘风格

设置面板 → **开启手绘风格**：节点边框、连线会渲染成手绘草图效果。
导出图片时同样生效，适合做讲解、演示的视觉风格。

### 画布动量

设置面板 → **开启拖动画布的动量效果**：拖动画布松手后带惯性滑动，浏览大图更顺滑。

### 同级节点对齐

设置面板 → **开启同级节点对齐**：同一层级的节点自动对齐。

### 自由节点树

"自由节点"是不受主结构约束、可任意摆放的节点（通过拖拽节点到空白处生成）。
自由节点成组后形成"自由节点树"，其根节点右键可**切换独立结构**，
或在结构面板选择"跟随主结构"。

### 禅模式

只保留画布，隐藏所有面板，专注绘制。可在设置或底部工具栏进入。

## 十、导入

点击右上角**导入图标**，支持两类方式：

**文件导入**（点击选择文件，或把文件拖进来）

| 格式 | 说明 |
|------|------|
| `.smm` / `.json` | 本插件私有格式，再导入后可继续编辑 |
| `.md` / `.txt` | 按 Markdown 标题层级解析为导图 |
| **`.opml`** | 大纲处理标记语言，可与幕布、OmniOutliner 等互转 |
| **`.mm`** | FreeMind 格式 |
| **`.xlsx`** | Excel 表格，导入时可选择要导入的画布（工作表） |
| XMind | `.xmind` 文件 |

**粘贴导入**

- **粘贴 Markdown 内容导入**：把 Markdown 文本直接贴进对话框
- **粘贴 Txt 内容导入**：纯文本按缩进/换行解析

**两个实用选项**

- **导入为当前激活节点的下级节点**：不覆盖整张图，把导入内容挂到当前选中节点下
- **转换数学公式**：把 `$...$` 形式的内容渲染成公式节点
- **解析出多个根节点时创建为自由节点**：避免多根内容破坏原结构

> 注意：导入会**覆盖现有内容**且无法撤销，导入前建议先复制一份文件备份。

## 十一、导出

点击右上角**导出图标**，或使用命令面板的导出命令。

| 格式 | 用途 |
|------|------|
| **思绪文件（.smm）** | 用于再次导入，跨设备迁移，保留完整配置 |
| **JSON** | 通用数据格式，可用于二次开发 |
| **Markdown（.md）** | 转成大纲式笔记，节点层级转为标题与列表，可设置"节点转标题的最大层级"与保留项（概要 / 备注 / 描述 / 图标 / 编号 / 标签） |
| **Txt** | 纯文本大纲 |
| **HTML** | 单文件网页，内嵌 SVG，可直接浏览器打开 |
| **Excel（.xlsx）** | 表格形式，便于用 Excel 编辑整理 |
| **FreeMind（.mm）** | 用 FreeMind / 其它脑图软件打开 |
| **Mermaid（.mmd）** | 生成 Mermaid 流程图代码，嵌入技术文档 |
| **OPML** | 与其他大纲软件互通 |
| **图片（png / jpg）** | 位图导出，可设透明背景、内边距、是否包含背景图 |
| **SVG** | 矢量图，无损放大 |
| **PDF** | 打印与分享；**PDF 中的节点超链接可以直接点击** |

**导出选项**

- 导出文件名
- 图片：内边距（上下 / 左右）、是否透明、是否包含背景
- Markdown：标题最大层级、保留哪些元素
- **附加文本**：统一加到导出内容末尾

## 十二、Markdown 与思维导图互转

任何 `.md` 笔记都能变成思维导图，思维导图也能随时转回 Markdown 笔记。两个方向都提供**覆盖转换**（改写当前文件）与**新建转换**（另存副本，原文件不动）两种方式。

**入口**

- 命令面板：`转换为思维导图文档`、`转换为Markdown文档`、`切换 Markdown / 思维导图视图`
- 文件标签右键菜单 → 更多选项：同一组命令

**Markdown → 思维导图**

按标题层级解析：一级标题成为根节点，二级、三级标题依次成为子节点，列表项作为叶子节点。转换后文件名不变，但会写入思维导图数据（frontmatter 增加 `simplemindmap` 标签，正文追加 `metadata` 数据块），之后打开会自动进入导图视图。

- 解析出多个同级根节点时，可选把它们作为**自由节点**摆到画布上
- 表格、图片、链接等无法映射成节点的内容会被丢弃，重要笔记请先备份

**思维导图 → Markdown**

按设置里的【节点转标题的最大层级】把导图转成大纲笔记，并保留概要、备注、描述、图标、编号与标签；转换后文件回到纯 Markdown，不再被识别为导图。

**切换视图（不改格式）**

`切换 Markdown / 思维导图视图` 只切换当前文件的打开方式，不动数据，在阅读视图与导图编辑视图之间来回切换。适合导图想重新排版成文章，或文章想临时用导图梳理的场景。

> 提示：导图转成 Markdown 后如果文件名仍是 `.smm.md`，双击文件仍会默认用导图视图打开。此时用【切换 Markdown / 思维导图视图】切回 Markdown 视图即可，文件内容不会被覆盖。

## 十三、smm 代码块嵌入

在**普通 Markdown 笔记**里直接写 `smm` 代码块，就能把思维导图嵌入到笔记正文中：

````markdown
```smm
{"root":{"data":{"text":"中心主题","uid":"a1"},"children":[{"data":{"text":"分支一","uid":"a2"},"children":[]}]},"theme":{"template":"classic","config":{}},"layout":"logicalStructure"}
```
````

**说明**

- 代码块内容为 **未压缩 JSON**，结构是 `{ root, theme, layout }`
  - `root`：节点树（`data.text` 是文字，`children` 是子节点数组，`uid` 需唯一）
  - `theme.template`：主题名（如 `classic`、`classic13`）
  - `layout`：结构名（如 `logicalStructure`、`mindMap`、`timeline`、`fishbone`、`table`）
- 渲染后可直接在笔记内编辑：拖动、缩放、改文字
- 视图右下角提供 **回到根节点**、**适应画布** 两个图标
- 右下角还有结构、主题下拉框，可即时切换
- 鼠标点到笔记其他位置时**自动把改动写回代码块**
- 支持拖拽调整嵌入高度；默认高度在设置中配置（**代码块初始高度**）
- 可设置代码块背景透明

> 注意：同一时间只能有一个插件占用 `smm` 这个代码块语言。如果安装了其它同样
> 注册 `smm` 的插件（例如 ob-smm），内联代码块会被对方接管而失效。
> 此时停用其中一个插件并重新加载 Obsidian 即可。

## 十四、新标签页预览为思维导图

任意 Markdown 笔记（不需要转换格式）都可以临时以导图查看：

1. 打开该 Markdown 文件
2. 点击右上角 **更多菜单（⋮）**
3. 选择 **预览为思维导图（新标签页）**

- 在新标签页中以思维导图方式呈现当前笔记的标题结构
- 原文件修改后，预览的导图会自动更新
- 预览标签页可切换只读，避免误改

还可以用命令面板：`把 Markdown 预览为思维导图（新标签页）`。

## 十五、演示模式与填空模式

**进入演示模式**

- 底部工具栏的**播放图标**
- 或命令面板 → `进入演示模式`

演示模式下：全屏展示、方向键翻页（右下角显示 `1 / 144` 形式的页码）、
左上角关闭按钮退出。

**填空模式**

在演示模式或画布右键菜单中开启"填空模式"，节点文字会变成填空样式，
用于教学、复习、演讲时先遮住答案再逐条展开。默认配置在
设置 → 演示配置 → **开启演示模式的填空功能**。

## 十六、字体管理

设置 → **字体管理** 中可添加自定义字体：

- 输入字体名称（需系统已安装，或通过 CSS 引入 web 字体）
- 添加后，**所有字体选择器**（节点样式、关联线样式、导出配置等）都会出现该字体
- 可在设置中删除不再使用的字体

## 十七、设置项一览（设置 → Your Mindmap）

**文件与保存**

| 设置 | 说明 |
|------|------|
| 文件名格式 | 新建导图的命名模板，支持 `{date:YYYY-MM-DD HH.mm.ss}` 等占位符 |
| 文件保存位置 | 仓库根目录 / 当前文件所在文件夹 / 指定文件夹 |
| 图片、附件保存位置 | 同上，可分别设置子目录 |
| 时间戳 | 新建时使用日期还是时间戳命名 |
| 自动保存时间 | 停止编辑后多久写入文件（默认 5 秒） |
| 版本检查 | 启动时检查是否有新版本 |
| 语言 | 简体中文 / 繁体中文 / English / Tiếng Việt，可跟随 Obsidian |

**编辑体验**

| 设置 | 说明 |
|------|------|
| 性能模式 | 大图时只渲染可视区域节点，提升流畅度（建议开启） |
| 节点自由拖拽 | 允许把节点拖到任意位置 |
| 节点富文本编辑 | 开启后节点内可使用粗体、颜色等富文本 |
| 鼠标滚轮行为 | 缩放视图 / 上下移动视图 / 左右移动视图 |
| 创建新节点的行为 | 激活并进入编辑 / 只激活 / 不激活 |
| 文本编辑实时渲染 | 输入时即时排版 |
| 节点间隔、图片与文字间隔 | 布局紧凑度 |
| 滚动条 | 是否显示画布滚动条 |
| 底部工具栏 | 是否显示 |

**风格与手感**

| 设置 | 说明 |
|------|------|
| 开启手绘风格 | 节点与连线变为手绘草图效果 |
| 开启拖动画布的动量效果 | 拖动松手后带惯性 |
| 开启同级节点对齐 | 同层级节点自动对齐 |

**导出与展示**

| 设置 | 说明 |
|------|------|
| 水印 | 文字、颜色、行距、字距、旋转角度，可选"仅在导出时显示" |
| 代码块初始高度 / 背景透明 | 控制 ```smm 嵌入的默认外观 |
| 公式渲染模式 | MathML / KaTeX |
| 演示配置 | 填空模式等 |

## 十八、移动端使用建议

- 支持 iOS / Android，但小屏手机上建议以**只读浏览**为主
- 在 **设置 → 性能模式** 中开启性能模式，大图更流畅
- 双击缩放、双指缩放/平移手势与桌面略有差异，多使用底部工具栏的"适应画布"
- 移动端编写建议使用**大纲模式**，比在画布上操作更快

## 十九、快捷键总表

| 快捷键 | 功能 |
|--------|------|
| `Tab` | 插入子节点 |
| `Enter` | 插入同级节点（后） |
| `Shift + Enter` | 插入同级节点（前） |
| `Shift + Tab` | 插入父节点 |
| `Ctrl/Cmd + G` | 插入概要 |
| `F2` / 双击 | 编辑节点文字 |
| `Ctrl/Cmd + C` / `X` / `V` | 复制 / 剪切 / 粘贴节点 |
| `Ctrl/Cmd + Z` / `Y` | 撤销 / 重做 |
| `Ctrl/Cmd + A` | 全选节点 |
| `Ctrl/Cmd + ↑` / `↓` | 上移 / 下移节点 |
| `Delete` | 删除节点（保留子节点） |
| `Shift + Backspace` | 删除节点及其子树 |
| `Ctrl/Cmd + P` | 打开命令面板（搜索 `smm`） |
| `Ctrl/Cmd + R` | 重新加载 Obsidian（安装/更新后使用） |
| 滚轮 | 缩放画布 |
| 空格拖动 | 平移画布 |

> macOS 上把 `Ctrl` 换成 `Cmd`。
